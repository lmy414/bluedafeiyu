# 图片关键词搜索

公开前端保持纯静态。搜索只读取已发布的 `/archive-data/{zh,en,ja}.json`，在浏览器里建立索引并匹配，不调用搜索 API、语言模型或向量服务，也不新增数据库与依赖。

## 检索字段和排序

`frontend/public/archive/search.js` 是独立检索模块，仅在搜索页按需加载。每次数据载入后整理一次名称、标签、全部角色及别名、图片描述、肥鱼说，以及当前语言的译文。简繁体使用已有的 OpenCC 归一，同时统一大小写、全角字符和标点。

索引使用字符与相邻双字符的倒排表缩小候选范围，再验证实际文本；多个关键词采用 AND，可分别命中不同字段。支持 `Intl.Segmenter` 中文分词；缺少该能力的浏览器保留完整短语和空格分隔的关键词检索。

默认按相关度排序：完整短语优先，再按名称、标签、角色、描述、肥鱼说的权重排列，同分保留原有作品顺序。搜索页仍提供最新、随机及角色、类型、创作方式筛选；图库和专题维持原有默认顺序。每次展示 24 件作品，继续沿用加载更多及 URL 状态。

`equivalents` 只维护少量明确的常用写法，如摸头／摸摸头、拥抱／抱抱、上班／打工。添加时同时补充检索用例。英文和角色拼写支持至少四个字符的一次插入、删除、替换或相邻换位，模糊命中降权；短词和中文单字不做拼写扩展。

重复查询复用有容量上限的缓存，筛选、排序和加载更多不重新处理原始文案。输入法组合输入期间等待文字确认，再触发搜索。更改公开文案后，随正常静态发布更新数据即可，不维护独立的远程搜索数据源。

## 验证

```sh
node --test frontend/tests/search.test.mjs frontend/tests/multi-character.test.mjs
npm --prefix frontend run check:components
node tools/build_site.mjs --content-dir <图片仓库路径> --out .build/site
npm --prefix frontend test
```

浏览器验收覆盖描述／肥鱼说关键词、连续中文词、繁体输入、角色别名、英文拼写容错、相关度／最新排序、条件筛选、加载更多、中文输入法及四种页面语言。搜索不扩展到未发布或已下架的作品。
