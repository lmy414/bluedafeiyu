# 新版前端方案 v3（演示，未接入正式构建）

日期：2026-10-29。基线：本地 `.build/site`，源提交 492ce49。线上为 19a88e2，比本地多两次后台内容发布，前端代码相同。

## 怎么看

- 运行 `node docs/redesign-v3/gen/build.mjs` 生成 `site/`，然后打开 `site/index.html`。构建时会读取线上下载统计，接口超时时最多等待 10 秒。
- 要测试复制图片、评论等需要正常网页来源的功能，在 `site/` 目录运行 `python -m http.server`，再打开 `http://127.0.0.1:8000/`。
- 演示只有简体中文。切换语言会跳到线上对应页面。
- 社群二维码随演示站生成，可直接在本地文件中显示。

## 原则：只升级样式、交互和视觉，内容与 URL 不变

- **页面清单与线上简体中文完全一致**：共 1740 页，另加 Google 验证文件。构建时逐一对比线上清单，少一页或多一页都会直接报错。连载页移出图库后，末尾几个分页没有作品了，这些页仍然保留，显示“已经到底了”和返回入口。
- **SEO 外壳原样复用线上**：每页的 title、description、robots、canonical、hreflang、Markdown 副本链接、og/twitter 标签和 JSON-LD，都从 `.build/site` 同一页读取后原样输出。H1 也用线上的文字（`gen/live.mjs`）。
- **正文内容来自线上**：关于、社群、活动回顾、更新日志的正文从线上页面转写；作品页的“来源作者 / 图片署名 / 来源 / 来源说明 / 授权状态”整段也从线上转写，作者的站外主页链接都保留。对比结果：1356 件作品中有 429 件带站外链接，全部与线上一致。
- **连载不进入主图库**：首页最新作品、图库及分页、GIF、类型页、角色页、角色×类型页、主题合集、作者页图片列表都不显示连载页。连载在漫画栏目（`/categories/comic.html` 顶部）、连载封面与目录、阅读器和搜索结果里出现。

## 保留并升级的交互

| 功能 | 演示中的做法 |
| --- | --- |
| 图片浏览 | 不对齐瀑布流：新卡片放进实际最矮的一列，阅读顺序从左到右、从新到旧；下滑自动加载，可以一直往下翻；页码保留在底部，不用脚本也能翻页 |
| 筛选与排序 | 类型、角色入口都是真实链接；页内另有“多选角色”“最新 / 最早 / 随机”“只看 GIF”，切换后在当前页重新排列并继续无限加载 |
| 作品预览 | 与线上信息一致：角色、类型、大肥鱼说、标签、来源作者、图片署名（站外主页）、原始来源、授权和备注；有下载原图、收藏、复制图片、复制链接、分享卡片；可以上一张、下一张、用 ← → 键、手机左右滑动、放大查看；图片按比例完整显示，信息区独立滚动，操作按钮保持可见 |
| 作品详情 | 大图完整显示，点击放大；信息卡依次是角色、标题、类型、大肥鱼说、说明、操作按钮、来源与授权；下面是相关作品和评论（giscus，点击后加载，配置与线上相同） |
| 连载 | 封面与目录按章节分组，缺页保留页码；页内“连续阅读”模式不新增 URL；单页阅读可以点图片两侧、用 ← → 键或手机滑动翻页；记住阅读进度，显示“继续阅读” |
| 视频 | 与线上相同，一页列出全部视频；按角色筛选（不按作者分组），可按发布时间或时长排序；作者入口放在创作者页 |
| 社区 | 顶栏和页尾都有“加入交流群”按钮，弹出二维码、群号和加入链接，可以复制群号；每页底部有“分享卡片” |
| 友情链接墙 | 按“全部 / 项目类 / 网站类”切换的卡片墙；页尾另列出全部友情链接 |
| 其他 | 收藏只存在本浏览器，与线上一致；搜索在浏览器内完成；明暗主题；按 / 聚焦搜索；“生态”菜单是顶栏下方的整宽面板，不会超出屏幕 |

## 导航：任意页面三次点击内到达其他任意页面

- 每页都有：顶栏的栏目入口，生态菜单（社区、生态、开放数据、关于），页尾的分组链接、友情链接和站点索引（包括 gallery、category、collections 三个旧入口）。
- 分页列出全部页码，同一栏目的任意一页都能一次点到。
- 连载封面页列出每一页作品详情的链接。
- 检查方法：用演示站点内的全部链接建图，对每一页做广度优先搜索（不计 404 页和 Google 验证文件）。结果是任意两页都在 3 次点击内：1 次可达 79,883 对，2 次 792,416 对，3 次 2,150,083 对。

## 视觉

- **“深海档案”配色**：深海蓝作主色，天青、珊瑚、紫、青绿区分频道。漫画用珊瑚色，视频用紫色，合集和友链用青绿色。角色页使用角色自己的颜色。
- **首页**：
  - 渐变海浪背景的主视觉，大搜索框和热门搜索词，作品扇形拼贴和统计数字。
  - 三个大入口卡（图库、漫画、视频），配图完整显示。
  - 六个快捷入口，后面依次是按角色找图、最新作品、热门下载（编号）、漫画连载与最新短篇、主题合集、最新视频、“一起参与”三色卡和常见问题。
  - 最新作品和热门下载使用对齐卡片，图片完整显示。下载量来自正式站的公开统计快照，表示下载按钮点击次数。页面标明快照更新时间；重新构建时刷新，演示站本身不记录下载次数。
  - 热门下载按快照中的下载次数排序，显示前 6 件。统计不可用时显示推荐作品和“下载量待同步”，不显示排名。
- **页头**：列表页有带统计数字的彩色页头；角色、合集和连载有大图页头。
- **作品卡**：卡片悬停时上浮，收藏心形按钮浮在图上；只在作品明确授权时显示授权标签。
- **吸顶筛选条**：只有一行，约 52px 高，下滑时不挡视线。角色头像条不吸顶。
- **手机**：底部有五项导航栏。筛选条的工具收成图标。在 390px 宽度下，抽查的 27 个页面都没有横向溢出。

## 检查结果

- 页面清单与线上一致：1740 页。
- 相对链接失效 0 处；图库类列表中出现的连载页 0 件。
- 作品页的站外作者和来源链接与线上逐页一致。
- 社群页内容和首页下载统计的回归检查：`node docs/redesign-v3/gen/verify-community-home.mjs`。
- 作品预览的浏览器回归检查：`node docs/redesign-v3/gen/verify-preview.mjs`。检查需要 `admin/` 的 Playwright 依赖，以及本机 Chrome 和 Edge。
- title、description 等 SEO 元素直接取自线上，所以线上原有的问题也原样保留：
  - 14 个创作者页的 description 只有个人简介；
  - 10 组同名作品的 title 重复；
  - 当期活动页、友链页、收藏页的 description 过短。

  这些问题列在下面的建议里，没有在演示中改动。

## 建议另外处理的问题（会改内容，需要确认）

1. 作品页 description 缺尺寸，标题重复。
2. 创作者页 description 只有简介。
3. 每页的对话框标题占用了 H2（分享卡片、交流群、空的打包标题）。
4. 部分列表页没有可见的面包屑。
5. 连载页使用的结构化数据类型可以改为 ComicSeries / ComicStory。
6. 视频页一页 653 KB，可以考虑分页或改为增量加载。

## 落地顺序建议

1. **修 bug**：上表第 1、3、4 条，并在发布流程补写图片尺寸。
2. **样式重建**：新建一份设计变量和组件样式（参考 `assets/site.css`），替换现在的多层覆盖链；作品卡只保留一个渲染器；同步更新 `demo-parity`、`demo-structure` 等结构测试。
3. **外壳**：顶栏替代侧栏；生态菜单、页尾和友情链接由频道清单生成（`gen/layout.mjs` 的 `CHANNELS`，正式实现可放进 `data/channels.json`）。
4. **交互**：
   - 瀑布流和无限加载、页内多选筛选、新的预览弹窗、连载的连续阅读模式。
   - 都在现有 `work-preview.js`、`paged-feed.js`、`ComicSeries.mjs` 上改；“只读取一次 JSON”的做法沿用。
5. **连载移出图库**：在构建时从列表数据源排除 `serial-topics.json` 的 `workIds`，计数随之变化（图库从 1356 件变为 1333 件）。
