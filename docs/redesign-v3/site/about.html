蓝色大肥鱼是什么？

蓝色大肥鱼是一个非官方同人整理项目，讲清楚它是干什么的、版权归谁、以及我们不收集你的哪些数据。

名字的由来

“蓝色大肥鱼”是 DeepSeek娘的社区昵称，也常被叫作“大肥鱼”“鲸鱼娘”或“哦鲸鲸”。据 17173 的报道，有网友把 DeepSeek 的蓝鲸标志交给模型辨认，模型给出了“蓝色大肥鱼”的评价，这个称呼随后在社区流传。这里讲的是社区玩梗与二创，不是官方角色设定。

关于本站

「蓝色大肥鱼」是收集 AI 娘二创表情包的开放档案：作品按角色归档，支持按名称、Tag 与角色别名检索；每张作品都有独立详情页，可以查看来源与授权、下载原图，还带一个独立的评论区。更新日志见页脚。

你能在这里做的事：按角色与分类浏览全部作品；用关键词搜名称、Tag 或别名；进详情页拿原图；在作品下留言讨论；也可以把自己的作品投稿进来。

当前公开归档 1356 件作品，其中 DeepSeek娘作品 1099 件。数量随作品收录和下架自动更新。

开放数据接口

提供已公开图片作品的静态 JSON 数据，支持角色、作品类型、标签、人工专题和作者作品集。使用 GET 请求，无需账号或密钥，返回 UTF-8 JSON，接口版本为 v1。

路径（相对于接口根地址）说明

works/{id}.json按稳定作品 ID 获取单件详情，返回 work 对象。
characters.jsoncategories.jsontags.jsontopics.jsoncreators.json分别获取角色、类型、标签、专题、作者目录，返回 items 列表。
characters/{id}.jsoncategories/{id}.jsontags/{id}.jsontopics/{id}.jsoncreators/{id}.json按对应目录中的 ID 获取作品索引和原图地址。专题保留人工编排顺序。

花括号表示需要替换的值。作品使用 id，不使用 slug；其他 ID 从对应目录读取。标签 ID 为 tag- 加完整 SHA-256 摘要，请直接使用目录给出的 worksUrl。

所有路径都是预生成的静态文件。筛选条件写在路径中；查询参数不会触发筛选。更多条件可由调用方根据完整元数据自行组合。

返回格式与字段

所有响应均有 apiVersion: 1。目录、清单和列表使用 items 与 total；作品详情使用 work。分类作品索引条目含 id、name、revision、detailUrl、originalUrl；完整字段从 works.json 或单件详情获取。分页另有 page、pageSize、totalPages、previous、next，首尾无相邻页时为 null。

字段说明
idslugname稳定作品 ID、详情页名称和标题；作品 ID 与 slug 发布后保持不变。
characterIdscategoryIdstopicIdscreatorIds角色、单选作品类型、人工专题和作者作品集的 ID；多角色作品会列出所有角色。
tags原记录标签；类型 ID 为 meme、illustration、setting、comic、standing、other。
image包含 originalUrl、thumbnailUrl、displayUrl、format、mimeType、animated、width、height、bytes、sha256。分别表示原图、缩略图、展示图地址、格式、MIME、动画标记、宽高、字节数及文件摘要；未知数值或摘要为 null。下载使用 image.originalUrl。
authorattributionsourcelicense原作者、公开收录署名、来源链接和逐作品授权；收录署名不等于作者身份。
revision作品元数据的 SHA-256 摘要，用于检测编辑；不同于 image.sha256 的图片文件摘要。
createdAtupdatedAt收录与更新日期；缺失时为 null。增量同步以 revision 为准。
i18n默认中文文本；已提供的英文和日文译文在 i18n.en 与 i18n.ja 中。

批量拉取与增量同步

首次可读取 works.json，或依次读取分页列表。之后保存 manifest.json 中的 ID 与 revision，只重新获取新增或摘要变化的作品；旧清单中存在、当前完整清单中消失的 ID 表示作品已下架。

读取前后核对 manifest.json 顶层 revision；如有变化，刷新清单后重试，避免跨发布版本混读。没有历史变更日志，也不使用时间查询参数。

存在的文件返回 200；不存在的 ID、页码或路径返回 404。响应内容随站点发布更新，客户端缓存可能短暂保留上一版本。

许可与版权

本站的程序代码以 协议发布，随便用。

但投稿或被收录的表情包不会因为进了本站仓库就自动获得 授权——图片的著作权始终归原作者所有。能不能用、怎么用，以每张作品详情页标注的来源与授权为准。

标注为「授权状态不明」的作品，请先联系原作者取得许可，勿直接商用。

  • 授权状态不明：本站未确认图片的使用许可；收录和提供下载不代表授予转载、改编或商业使用权。
  • 投稿者确认授权收录与下载：仅记录投稿者对本站收录和下载的许可，其他用途需向权利人另行确认。
  • 原作者明确授权：具体允许的用途以作品的授权备注为准；未明确允许的用途请联系原作者。
  • CC0 公共领域：作品记录标注为 CC0；使用时仍需核实原始声明及第三方权利。
  • CC BY 署名：遵守原作者声明的署名条件；协议版本以原始声明为准，本站不推定版本。
  • CC BY-NC 署名·非商用：遵守署名和非商业使用条件；协议版本以原始声明为准，商业用途需另行取得许可。

如何取得图片使用许可

打开对应作品，查看来源作者、来源链接和授权备注，通过原作者的公开主页或原始发布页面联系权利人，并说明作品链接、用途及是否商用。作者或来源未标注时，可通过下方「署名与删除申请」提交作品链接，请维护者协助核实来源；本站无法代未知权利人授权。
