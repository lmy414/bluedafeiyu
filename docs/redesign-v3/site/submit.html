投稿

把你的 AI 娘二创交给我们归档。支持单张图片或 ZIP 图片集，也可以走 GitHub 表单；图片逐张审核，通过后批量发布。

图片作品投稿视频创作者登记投稿指南

图片作品投稿

拖入或选择文件PNG / JPG / GIF / WebP / APNG，单张 ≤ 10 MiB；ZIP ≤ 32 MiB、最多 100 张
角色 * 可多选，勾选图片中出现的全部角色
提交前确认 *
去线上表单提交演示页不上传文件

投稿指南

投稿先进入审核队列，审核通过后批量发布。维护者会核对作品类型，并补充标签、来源和授权信息。

ZIP 仅可包含图片，不支持加密或嵌套压缩包；包内图片共用本次填写的信息，每张独立审核并自动去重。

GitHub 投稿表单授权说明在 QQ 群投稿

作品类型怎么选

梗图
单幅画面，表达梗、吐槽、态度或聊天反应
插画
人物、场景、氛围与艺术构图，含头像和半身像
设定图
明确的设计参考：三视图、结构拆解、色板或部位标注
漫画
两个及以上明确分格或分镜，可表达反应、对比或笑点，不要求叙事
立绘
简单背景上的独立人物，展示完整或接近完整的造型与姿态
其他
形式特殊或信息不足，无法可靠归入前五类的图片
